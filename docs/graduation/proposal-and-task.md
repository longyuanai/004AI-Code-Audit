# 毕业设计开题与任务书通用草稿

题目：基于 Python 与大语言模型的源代码安全检测系统设计与实现。
专业：计算机应用技术。学生、学号、学校、指导教师、开题日期与学校审批栏由本人
按学校实际信息补充。本稿没有学校签署或批准含义。

## 选题与目标

以现有 AI-Code-Audit 为基础完善 Python 本地源代码审查流程，使使用者能够安全
导入源码、创建扫描任务、查看潜在风险及证据、选择模型复核、查询历史并导出报告。
将工程验证和小规模标注实验作为结果依据，避免仅凭模型解释认定漏洞。

## 工作内容

先审计项目和跑既有测试，再实现受限导入、五类语法风险、任务及数据库、Web
流程和报告。对上传、路径、资源限制、模型降级及输出转义进行验证。固定通过
测试的本地提交，从 Git 导出只读源码快照，提供离线依赖及部署说明。最终编写
需求与设计、测试报告、通用论文和答辩材料，按后续学校模板调整。

## 技术路线与可行性

复用 Python、Tree-sitter 和 shared-llm-core，补充标准库 AST、SQLite、HTTP 和
浏览器静态页面。模型使用已部署本地 Ollama 指令模型，不要求云端密钥。项目
不执行上传代码，没有公网账号或自动修复执行。需求、数据库和接口合并在系统
设计中，避免重复文档。

## 已执行阶段与后续学校安排

2026-10-09 已现场开展基线审计、核心实现、真实测试、受控模型实验和材料编制。
具体验收提交及导出检查由交付清单记录。本稿不倒填开题审批时间或虚构周计划。
后续由学生取得学校模板，补个人信息，复核标签，准备现场演示并提交学校审核。

## 预期交付

验收源码快照、可离线安装软件、配置示例、测试与标注样本、需求和系统设计、
部署与操作手册、真实测试报告、论文通用初稿及可编辑答辩 PPT。检测性能承诺
仅限实际样本和本机环境，学术验收不由软件测试替代。
