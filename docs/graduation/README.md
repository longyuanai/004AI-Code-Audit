# 毕业设计准备材料

题目暂定为《基于 Python 与大语言模型的源代码安全检测系统设计与实现》。
这些材料依据 2026-10-09 真实实现和验证编写，属于通用草稿。学校模板尚未提供，
本机静态与真实 Qwen 3B 复核流程已经验证。最终源码提交、导出与独立安装证据
由正式交付清单记录，学校学术及格式验收仍待本人办理。

| 材料 | 用途 |
|---|---|
| [基线审计](../audits/graduation-baseline.md) | 初始代码、功能缺口、Git 状态、最小修改方案 |
| [需求与系统设计](system-design.md) | 技术规格、业务流程、模块、数据库、API；避免重复制造独立文档 |
| [测试报告](../tests/graduation-test-report.md) | 实际命令、失败修复、实验数据、截图、未验证项 |
| [部署与使用手册](deployment.md) | 开发运行、离线安装、配置、操作、备份、回滚 |
| [论文通用初稿](thesis-draft.md) | 七章结构与真实实现，待学校模板调整及模型实验补充 |
| [演示与答辩提纲](defense-outline.md) | 幻灯片内容草稿、演示步骤、常见问题 |
| [开题与任务书草稿](proposal-and-task.md) | 范围、技术路线与交付要求，待学校模板和本人信息 |

正式交付目录 `毕业设计/AI代码安全检测系统` 尚未生成源码快照。必须先补齐真实
完整版本 Git 状态并固定验收提交，再从该提交导出最终源码，
打包通用 PDF/PPTX 和可编辑 Markdown。当前安装验证产物位于 artifacts/，不是第二
套活跃开发仓库或已发布版本。没有打标签、远程推送、合并主分支或发布。

当前实现不含账号、多用户授权、人工审核工作流、修复代码执行、依赖漏洞扫描或
公网服务。保留套件原 CLI 和相关历史文档；本地毕业设计范围以本目录和测试报告为准。
